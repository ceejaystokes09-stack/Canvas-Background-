# Colour Drift

A lightweight, mesmerizing web animation featuring smooth, floating, drifting gradient orbs rendered via the HTML5 `<canvas>` API with a subtle backdrop blur effect.

## Features

* **Dynamic Animation:** Floating orbs drift gently using smooth trigonometric motion (`sin`/`sin` waves).
* **Radial & Linear Gradients:** Custom color palettes create depth with glowing centers, soft edges, and optional borders.
* **Responsive Design:** Automatically resizes and scales correctly across different screen resolutions and high-DPI (Retina) displays.
* **Zero Dependencies:** Built completely in vanilla HTML, CSS, and JavaScript with no external libraries or frameworks required.

## Files Included

* `index.html` – The main structure and styling containing the full-screen canvas and blur overlay.
* `index.js` – The core animation logic, color palettes, and rendering loop.

## Getting Started

To run this project locally, simply follow these steps:

1. Clone or download this repository.
2. Ensure both `index.html` and `index.js` are in the same folder.
3. Open `index.html` in any modern web browser.
